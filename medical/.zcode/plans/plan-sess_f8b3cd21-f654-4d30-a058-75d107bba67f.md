# 医学文献知识库构建方案（相关性优先版）

## 目标
从 6 个期刊 OA 官网下载 **约 80 篇与项目最相关**的文献（PDF + 提取文本 + 元数据清单），作为"杏林大健康 AI 问答系统"的 RAG 知识库起步语料。

## 相关性标准（从需求文档推导）
文献按需求文档的 18 类固定问答和健康咨询场景选题，优先：

1. **主题命中**——需求文档涉及的高频咨询疾病与维度：
   - 常见病/慢病：感冒·流感·咳嗽·哮喘·肺炎、高血压·冠心病、糖尿病·高血脂·痛风·肥胖·脂肪肝·甲状腺、胃炎·便秘·腹泻、失眠·头痛·脑卒中、骨质疏松、尿路感染等
   - 咨询维度：症状学、药物治疗、饮食营养宜忌、预防与健康管理、检查检验、并发症
2. **文献类型加权**：综述 / 指南与共识 / 系统评价·Meta分析 > 临床研究论著（综述类信息密度高，最利于 RAG 回答大众咨询）
3. **优先近 3 年**（2023-2026）文献，保证知识时效性

## 选题与下载流程（两阶段，可审计）
```
Phase A 发现:  各刊抓取近年期次目录（Magtech 期次页含栏目名+标题；pangupress 有 search 页）
              → 候选池 candidates.jsonl（标题/栏目/年卷期/URL）
Phase B 筛选:  按主题词典+栏目类型打分排序 → 跨刊取 Top 80（每刊上限见下）
Phase C 下载:  PDF 校验（%PDF头、>50KB）→ PyMuPDF 提取文本 → manifest.jsonl
```
- 每刊上限（按贴合度递减，总80）：**中国全科医学 ≤30**（全科/慢病管理/综述栏目最多，最贴合）、基础医学与临床 ≤15、精准医学杂志 ≤12、中山学报医学版 ≤12、临床医药循证研究 ≤8、巴楚医学 ≤5；被 403/JS 挡住的刊由其余刊按分数补足。
- KB_README.md 附**主题覆盖分布表**（哪些疾病/维度各命中几篇），方便你核对选题是否符合预期。
