# 杏林大健康 AI 问答系统

**2026.XX - 2026.XX**（起止时间请按实际填写）

## 项目背景

通用大模型直接用于医疗健康问答存在三个硬伤：**医学幻觉不可控**（会把推测讲成结论）、
**结构化知识取不到**（疾病—症状—用药—就诊科室这类关系是确定的，却无法枚举）、
**回答无来源不可追溯**（用户无从判断依据）。

本项目面向"大健康咨询"垂直场景，从**知识构建 → 双路召回 → 事实护栏 → 工程化评测**
搭一套**可溯源、可降级、可量化**的问答系统：覆盖 8808 条疾病结构化知识与 19 篇医学文献，
按"能穷举的问题走确定性快路径、开放问题才动用大模型"的原则分工，并对无依据回答如实拒答。

## 技术栈

Python / LangChain + LangGraph / Neo4j（知识图谱）/ Milvus（向量库）/ Redis /
FastAPI / DeepSeek（LLM）/ Pydantic / Sentence-Transformers / jieba + BM25 /
RRF 融合 / NL2Cypher / DDD 四层架构 / pytest

## 工作职责

**1、知识层构建与确定性快路径**：把 8808 条疾病语料建构成 **7 类节点、10 类关系**的医学
知识图谱（含 **16783 条**「疾病—科室」关系），19 篇医学文献切成 **762 条**切片入 Milvus；
落地 **20 类固定问答**（业务定义 18 类 + 就诊科室场景扩展 2 类）的**模板化 Cypher 查询**，
**零 LLM 调用、结果确定**。把类别编号与名称**逐字固化为断言**，防止后续改动悄悄漂移。

**2、双路召回与融合调优**：稠密（向量语义）+ 稀疏（BM25 + jieba 分词）双路做 RRF 融合。
通过**权重消融实验**发现原默认权重 `0.6/0.4` 会让融合**退化成单路**（结果与"仅稠密"
**逐位相同**，稀疏路毫无贡献），调整为 `0.5/0.5` 后要点覆盖率 **92.1% → 97.4%（+5.3pp）**；
单次检索耗时 **0.048s**，并把权重做成可配置项以支持持续调优。

**3、自动选路与降级容错**：设计"**开放程度优先于问题类型**"的选路策略
（direct / kg / rag / hybrid）与换路重试（≤2 次），寒暄类输入不触发任何检索。
**6 个依赖拉闸场景全部通过**——停图谱、停向量库 + 删 BM25 语料、LLM Key 失效、
停 Redis、护栏 LLM 超时、护栏返回乱码，系统均**不抛异常且如实反映能力下降**；
并修复"LLM Key 失效时把 401 异常直接抛给用户"的严重缺陷（降级为模板回答，
内容 100% 来自证据、零幻觉）。

**4、防幻觉与安全防线**：实现基于**第二次 LLM 调用**的事实护栏（核查答案是否忠于证据，
**提醒不拦截**，实测误报 **0 次**）；**12.7 非法查询入口拦截**覆盖中文 / 英文 / Cypher
写操作与越权索取，把非法请求从"走完检索 + 大模型共 4.28s"压缩到 **0.00s 直接拒绝**；
配合 Cypher 全参数化、Neo4j 只读会话、只读校验器形成**四道防线**，注入串无法进入语句。

**5、DDD 分层架构与自建评测体系**：按 interface / application / domain / infrastructure
四层落地，**依赖方向用 AST 静态测试固化**（跨层引用会直接让单测失败）；自建评测体系——
从图谱**自动生成 160 条固定问答题**（真值 Cypher 手写、**不 import 生产代码**，避免
"代码错真值也错、评测永远通过"）、57 条开放题、19 条**语义改写**题、28 条边界与安全用例；
沉淀 **199 个离线单测**（零外部依赖、可进 CI）；用消融实验证明结构化知识的价值
（**自动选路 90% vs 强制纯文献 0%**）；并发压测 **20 并发零错误**、P50 稳定在 5s。
